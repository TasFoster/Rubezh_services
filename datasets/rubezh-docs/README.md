# Документация Rubezh — набор данных

Локальная база документации, руководств, паспортов, сертификатов, изображений и
ПО производителя **RUBEZH**, собранная для разработки сервисов (в первую очередь
«Помощника в принятии решений тех. поддержки»).

## Охват (текущий этап)

- **R-PLATFORMA** — интеграционная платформа (PSIM)
- **RUBEZH STRAZH** — система контроля и управления доступом (СКУД)

> Планируется расширение на другие линейки (RUBEZH R3, FireSec и т.д.).

## Политика хранения в Git

⚠️ **Сами файлы (PDF, изображения, ПО) НЕ коммитятся в репозиторий** — это
гигабайты бинарных данных, несовместимые с обычным git/GitHub (лимит файла
100 МБ). Они лежат только локально.

В репозиторий `Rubezh_services` попадают:
- этот `README.md`,
- `INDEX.md` (сводка: сколько файлов, объём, разбивка),
- `_manifests/*.csv` (полный перечень «файл → источник → размер»).

Полный набор восстанавливается скачиванием по манифестам. Если потребуется
хранить сами файлы в облаке — использовать Git LFS или внешнее хранилище.
