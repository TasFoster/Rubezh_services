## Ключевое содержимое

### RUBEZH STRAZH
- **Паспорта (ПС):** контроллеры STR20-IP / STR20-IP-Ent / STR20-1AP/2AP-IP-M; модули доступа STR-1AP/2AP/3AP(-M); считыватели STR-RM-A01/B01/S01, STR-RMO-H01; турникеты 3V RUBEZH STRAZH (Model A/L/R/V/T/Y)
- **Руководства по эксплуатации** турникетов и оборудования
- **11 DWG-чертежей** — габаритные чертежи контроллеров, модулей, турникетов
- **Сертификаты и декларации:** ТР ТС 004/2011, ТР ТС 020/2011, ТР ЕАЭС 043/2017, ГОСТ Р 71934-2025, ПП РФ 719/969, СТ-1, транспортная безопасность (R-Охрана, R-Доступ)
- **Схемы подключения** (OSDP/Wiegand)
- **ПО FireSec NT** 3.2.7 / 3.2.9 / 3.2.10 / 3.2.11 (4 архива)
- **Прошивка STRAZH** `rubezh_strazh_firmware.zip` (446 МБ): образ `strazh-skd-1.2.220426.642` (.img.tgz) + пакет обновления (`update-package-...-full.bin`)
- **Буклеты решений:** портфолио, интеграции, презентация турникетов, Web-турникет 2023, OSDP-замок 2023, STRAZH 2022/2024
- **43 изображения** оборудования + схемы состава турникетов

### R-PLATFORMA
- **Руководства** администратора и оператора ПО R-PLATFORMA
- **Буклет** RUBEZH_PLATFORMA_2026
- **Сертификаты совместимости с ОС:** Astra Linux SE 1.7/1.8, RED OS 7.3/8; сертификат КАПС (продление до 2028)
- **ПО GLOBAL RUBEZH:** лицензирование (Linux/Windows) + РЭ (GLOBAL monitor 2.8.7)
- **Мобильное приложение R-OPERATOR** (apk)
- **Инфографика** решений и системные схемы
- **Материалы обучения** (курсы edu.rubezh.ru; видеокурс — на YouTube, ссылка ниже)
