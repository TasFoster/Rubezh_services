# Rubezh Services

Монорепозиторий-хаб для сервисов и приложений компании **Рубеж**.

Этот репозиторий хранит **общие сводки, документацию и наборы данных**, которые
используются при разработке отдельных сервисов. Сами сервисы живут в собственных
репозиториях (см. раздел ниже).

## Структура

```
Rubezh_service/
├── datasets/     # Общие наборы данных, используемые при разработке
├── summaries/    # Сводки, аналитика, справочные материалы
└── README.md
```

## Сервисы и приложения

| Проект | Репозиторий | Описание |
|--------|-------------|----------|
| Помощь в принятии решений тех. поддержки | [Rubezh_tech-support](https://github.com/TasFoster/Rubezh_tech-support) | Приложение, помогающее специалистам тех. поддержки принимать решения |

> Каждый сервис — отдельный Git-репозиторий. В этом хабе лежат только общие
> данные и документация, переиспользуемые между проектами.

## Как добавить новый сервис

1. Создать отдельную папку внутри этого хаба для локальной разработки.
2. Инициализировать в ней отдельный Git-репозиторий и запушить в свой remote.
3. Добавить папку в `.gitignore` этого репозитория (чтобы избежать вложенных репозиториев).
4. Добавить строку в таблицу «Сервисы и приложения» выше.
